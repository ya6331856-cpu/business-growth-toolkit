# ServiceKitly

Practical calculators and business tools for small service businesses.

## Current tools

- House Cleaning Price Calculator
- Profit Margin Calculator
- Hourly Rate Calculator

## Local development

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Before deployment, run:

```bash
npm run typecheck
npm run build
```

Calculators provide planning estimates, not financial, tax or legal advice. Review local market and regulatory requirements.

The canonical domain is temporarily configured as https://servicekitly.com. Update metadata, sitemap and robots if another domain is chosen.
